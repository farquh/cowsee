## [0.1.0] - 2025-09-11

### Added

- Initial release of the cowsee project. 
- This project is directly inspired by [cowsay](https://en.wikipedia.org/wiki/Cowsay). 
- The idea is to display geospatial geometry data in the command line.
- Maybe you could use it to quickly look at geometries without opening any applications. 
- Otherwise, there is little to no utility to this project.
